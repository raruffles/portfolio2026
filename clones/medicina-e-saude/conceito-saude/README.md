# Clone — Nova Dental

Clone fiel e independente do site [Nova Dental](https://nova-dental-dev.webflow.io/).

## Características
- **Assets 100% locais**: Folhas de estilo Webflow, Splide CSS, scripts do Webflow com todos os chunks dinâmicos, GSAP, ScrollTrigger, SplitText, Inputmask e fontes Neue Montreal baixadas e referenciadas localmente.
- **Interações**: Sliders Splide, animações GSAP de scroll e modal de agendamento preservados.
- **Console limpo**: Zero erros de JavaScript, zero erros 404 e sanitização completa de atributos `srcset`.

## Como Executar
Na raiz do repositório:
```bash
npm run dev
```
Acesse no navegador:
```
http://localhost:3000/clones/nova-dental/
```
