# More Nutrition (Matcha meets Protein) — Clone Local

Clone local completo e funcional da landing page **More Nutrition - Matcha meets Protein**, extraído e estruturado com a skill `ai-website-cloner-template`.

## 📌 Informações da Fonte
- **URL Original:** [https://more-nutrition.webflow.io/](https://more-nutrition.webflow.io/)
- **Segmento:** E-Commerce D2C / Produto de Nutrição & Bem-Estar (Iced Matcha Latte com Proteína)
- **Tecnologia Original:** Webflow, Canvas Image Sequence / 3D Can Rotation, Lenis Smooth Scroll, Custom Sticky Scrollytelling

## 🎨 Design Tokens & Estilo
- **Tipografia:** Custom Grotesk geométrica bold & Display branding typography
- **Paleta de Cores:**
  - Background Primário: Matcha Green Pastel (`#B6CBA5`)
  - Accent Dark: Deep Forest Matcha (`#1E4324`)
  - Accent White: Clean Milk / Foam (`#FFFFFF`)
- **Destaques:** Animação de lata rotacionando em canvas guiada pelo scroll do usuário, badges de macronutrientes circulares com linhas de conexão, seção de benefícios em grid bento minimalista e reviews em carrossel.

## 📂 Estrutura de Arquivos
- `index.html`: Código HTML completo com assets e estilos localizados.
- `assets/`: 103 imagens e texturas de produto (`.webp`, `.png`, `.jpg`).
- `screenshot_more_desktop.png`: Captura do viewport inicial desktop.
- `screenshot_more_full.png`: Captura da página completa.
