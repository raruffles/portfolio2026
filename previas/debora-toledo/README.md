# BCG Building Design — Clone Local

Clone local completo e funcional do site **BCG Building Design** (Gold Coast, Austrália), extraído e estruturado com a skill `ai-website-cloner-template` (JCodesMore).

## 📌 Informações da Fonte
- **URL Original:** [https://www.bcgbuildingdesign.com.au/](https://www.bcgbuildingdesign.com.au/)
- **Segmento:** Boutique Building Design Studio (High-end Custom Homes & Major Renovations)
- **Localização:** Gold Coast, QLD, Austrália
- **Tecnologia Original:** Webflow, Lenis Smooth Scroll, GSAP Interactions

## 🎨 Design Tokens & Estilo
- **Tipografia:** Neue Haas Grotesk Display Pro / Neue Haas Grotesk Text Trial
- **Paleta de Cores:**
  - Background Primário: Off-white / Warm Gray (`#F9F9F8` / `#F4F4F2`)
  - Accent Dark: Deep Slate / Charcoal (`#1A1A1A`)
  - Accent Earth: Muted Sand / Terracotta
- **Layout:** Grid assimétrico editorial de alto padrão com rolagem horizontal em seções de destaque e tipografia monumental.

## 📂 Estrutura de Arquivos
- `index.html`: Código HTML completo com caminhos de assets localizados.
- `assets/`: Estilos CSS (`style_1.css`, `style_2.css`) e imagens em alta definição (`.webp`, `.avif`).
- `screenshot_bcg_desktop.png`: Captura do viewport inicial desktop.
- `screenshot_bcg_full.png`: Captura da página completa (full-page).
- `screenshot_bcg_local.png`: Captura da execução do clone local via servidor.

## 🚀 Como Executar Localmente
Com o servidor de desenvolvimento rodando na raiz do repositório:
```
http://localhost:3000/clones/bcg-building-design/
```
