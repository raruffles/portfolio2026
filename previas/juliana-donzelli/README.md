# Juliana Donzelli | Arquitetura + Interiores

Landing page de altíssimo padrão e portfólio digital adaptado para a arquiteta e urbanista **Juliana Donzelli** (São José dos Campos - SP), baseada na engenharia editorial internacional do BCG Building Design / Débora Toledo.

## 🎨 Engenharia Visual & Tecnologias

- **Lenis Smooth Scroll v1.0.45** (Rolagem inercial fluida a 60fps)
- **GSAP v3.15.0 + ScrollTrigger + SplitText** (Revelação tipográfica cênica e galeria com pin horizontal)
- **Design Tokens:**
  - Tipografia: *Cormorant Garamond* (títulos/logotipo editorial) e *Neue Haas Grotesk* (leitura limpa e contemporânea)

## 🚀 Como Executar Localmente

Com o servidor de desenvolvimento rodando:
```bash
http://localhost:3000/clones/arquitetura/juliana-donzelli/index.html
```
Ou rodando isoladamente na pasta:
```bash
npm run dev
# Abre em http://localhost:3004
```
